# Bateria Score

Editor de partitura para bateria que funciona no iPhone como app (PWA).

**Instalar:** abra https://leandrovidotto.github.io/bateria-score/ no Safari do iPhone e toque em
**Compartilhar › Adicionar à Tela de Início**.

Recursos: figuras da semibreve à semifusa, pontos de aumento, pausas, quiálteras (3:2, 2:3, 4:3, 5:4, 6:4, 7:4, 9:8),
fórmulas de compasso (incluindo C e ¢), notas fantasma, acento e marcato, flam, drag, buzz roll, manulação, ritornelos
e impressão em PDF (A4 ou Carta). Funciona sem internet; as partituras ficam salvas no aparelho.
